# TFAI — World of TFAI

Next.js 15 editorial website starter for a boutique model management agency based in India and Sri Lanka.

## Start

```bash
npm install
npm run dev
```

Pages: `/`, `/models/women`, `/models/men`, `/models/kids`, `/about`, `/nude-media`, `/apply`, `/contact`.

**Before launch:** Homepage Unsplash photos are temporary reference photography, not official TFAI assets. Model portfolio photos are placeholders. The application page currently provides an email link; secure application form, uploads, parental consent, model profiles, CMS, Instagram photo slider and newsletter storage are future work. The current version does not persist user data.
